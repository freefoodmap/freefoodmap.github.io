#004 · HOW TO START

我也想开始。
该怎么做?

不需要大资金、不需要 NGO 资质。哪怕是 50 元钱 + 一个周末,就能做一次小型的免费食品发放。

01
Find your why

想清楚为什么

是想帮流浪汉?社区独居老人?学生?想清楚了,你才能撑过举报、警察、不理解。

02
Mini pilot

先做最小版本

不要一开始就搞 1000 人。先做 30 人。

03
Know the law

先看当地法规

中国大多数城市支持"邻里互助",但食品来源、发放点选址、食安标准有要求。

04
Sourcing

食物从哪儿来?

四个主要渠道:① 自掏腰包;② 临期超市/烘焙店捐赠;③ 联系当地 food bank;④ 餐饮店收尾餐。

05
Record it

拍视频。这是小唐最大的招。

一段 60 秒的真实视频,可能带来 100 倍的传播。

06
Scale up

做 3 次,再谈扩张

连续做 3 次,把流程跑通。然后拉 2-3 个朋友一起。

前辈踩过的坑,提前告诉你

⚠
被举报怎么办?

准备好执照、卫生证明、合作协议;被举报时保持微笑,先配合。

⚠
怎么避免被消耗?

不要每周发 7 天。固定 1-2 天,其他时间留给自己的生活和工作。

⚠
怎么拿到钱?

视频流量分成、企业冠名、众筹、当地 church 拨款、餐厅尾餐折现。

⚠
要不要注册 NGO?

先做 1 年再说。注册成本高、合规要求多,先做 informal network。

小唐一个人做不了所有的事。
但你,加上地图上几十个邻居,可以。

#006.B · HOW TO JOIN

如何加入

不需要签合同、不需要交钱、不需要开会。GitHub 一个 PR,或一封邮件,就可以开始。

01
告诉我们你能做什么

在 GitHub 开 issue / PR(代码或翻译),或直接邮件 open@freefoodmap.org。说清楚:技能、时间、城市、联系方式。

02
一周内回复,加你到协作者列表

你的名字会出现在 GitHub README 和站点的 #ambassadors 区,所有 commit 都会保留你的署名。

03
共建下一版,让网络长得更大

路线图在 GitHub Issues,我们一起决定下一站:加语言、加国家、加功能。所有人都是 committer,所有人都是 owner。

"The world is changed not by one person, but by the network of people who choose to show up."
GitHub · 提个 issue / PR → ✉ 邮件 · open@freefoodmap.org
