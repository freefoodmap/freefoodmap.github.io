# WeChat / 朋友圈 / 即刻 · 短帖模板

> **平台:** 微信朋友圈 / 微信群 / 即刻 / 微博 / 小红书
> **调性:** 个人化、有人情味、不写"项目",写"我做了什么"
> **目标:** 让朋友 → 朋友的朋友看见,带来 50–200 个点击

---

## 朋友圈版本(中英双语,选一)

### 中文版(推荐)

```
最近做了一件挺有意义的事。

一个在 LA 的河南小伙,免费给流浪汉发酱香饼,
最近宣布要竞选洛杉矶市长。
B 站他的视频我看了几十遍。

我想:他一个人能做的,不止他一个人。
2026 年 AI 能写诗能开车,
全球却还有 7.3 亿人在挨饿。

我做了一张地图,现在 60+ 个真实免费食品发放点,
覆盖 31 个国家,从 Feeding America 到绿洲盛食社。

技术上:纯静态,零后端,50KB,
git push 90 秒上线(对,这是项目代码:
github.com/freefoodmap/freefoodmap.github.io)

如果你在某个城市,想帮我们核对 3-5 个本地 food bank,
或者翻译成你母语(西/法/阿/印/斯瓦都行),
一封邮件就够:open@freefoodmap.org

或者:
看看这张图就行,里面可能就有你身边的免费食物。
https://freefoodmap.github.io

不一定要转发,
但如果你身边有人最近在找"附近哪有免费吃的",
转发给他,就是帮忙。
```

### 英文版(给海外朋友圈)

```
Spent the last 3 weeks on something I'm kinda proud of.

A 90s kid from Henan, China has been giving away free
scallion pancakes in LA's slums since 2022. He was arrested
twice. Last month he announced he's running for LA Mayor
in 2029. His slogan: "Vote for me as Mayor in three years."

I kept thinking: what if other people in other cities
could do the same thing — and had a map to find each other?

So I built freefoodmap.github.io.
60+ real free food points across 31 countries.
Feeding America, Trussell Trust, Oasis Food Bank,
KFC food cabinets, Robin Hood Army...

Tech: pure static, zero backend, 50KB total.
Deploy = git push. 90 seconds.

If you're in a city and want to verify 3-5 local food banks,
or translate to your native language (ES/FR/AR/HI/SW wanted),
just open an issue or email open@freefoodmap.org.

Or: just look at the map. Maybe there's a free meal
nearby you didn't know about.
```

## 适合发的群(分类)

| 群类型 | 时机 | 内容 |
|---|---|---|
| **老同学群** | 周末上午 | 完整版(中英),带"我从这事开始" |
| **行业群(tech)** | 周中晚上 | 短版 + GitHub 链接 |
| **海外华人 / 留学生群** | 任意 | 短版 + 强调"如果你在的城市" |
| **公益 / NGO 群** | 任意 | 完整版 + #ambassadors 强调 |
| **老家亲戚群** | 节日 | 中文完整版,带"小唐是河南小伙" |
| **即刻 / 微博 / 小红书** | 任意 | hook + 链接,不解释 |

---

## 反模式

- ❌ 标题党("震惊!AI 时代!重新设计分配!")— 显得营销
- ❌ 一上来就放 GitHub 链接 — 朋友不在乎代码
- ❌ 一次性刷 10 个群 — 退群警告
- ❌ "求转发" — 公益不需要求
- ❌ 链接到一个 Medium 跳板 — 朋友圈容易被限流
- ❌ 不写"我为什么做这个" — 没故事,没人转发

## 转化追踪(简易版)

发完朋友圈 / 群,自己数 24h:
- 链接点击:Bitly / 短链 计数
- 朋友私信问"这是啥"的数量
- 朋友加你好友并开始对话:"我也想参与"
- 站点当日 UV

> 朋友圈帖子不需要每天都发,每周 1–2 条即可,别刷屏。
