## 正文(Markdown)

```markdown
https://freefoodmap.github.io

事情的起因:

4 月份,有个在洛杉矶的 90 后河南小伙宣布要竞选 2029 年洛杉矶市长。
他叫"小唐",2022 年去的美国,做酱香饼,被举报、被徒弟背刺、被警察
拷走过两次,交了 13 万美元保释金,然后摊位搬到贫民区,开始**免费**
给流浪汉发酱香饼。

他火了之后我一直在想一件事:在 2026 年,AI 能写诗、能开车、能写代码,
全球却还有 7.3 亿+ 人在挨饿,每年 13 亿吨食物被浪费。

**技术最大的善意,是不是重新设计分配机制?**

这个站点就是这种想法的起点:

- 60+ 个**真实**免费食品发放点(Feeding America、Trussell Trust、
  绿洲盛食社、肯德基食物驿站、Robin Hood Army、欧洲 food bank 联盟)
  覆盖 31 个国家,Leaflet + OpenStreetMap,可按类型筛选
- 中英双语,240 个 key,默认中文,`?lang=en` 切换
- 3 个真实视频(B 站小唐本人)+ 3 个平台搜索直链
- 6 步起步指南:从"想清楚为什么"到"做 3 次再谈扩张"
- 4 个前辈踩坑提醒:被举报怎么办 / 怎么不被消耗 / 怎么拿到钱 /
  要不要注册 NGO
- **新加的 #ambassadors 区块**:6 种角色(工程师 / 本地联络人 /
  翻译 / 影像记录 / 外联 / 设计师),创始人 + 5 个开放 slot

技术栈:
- 纯静态,**零后端**
- HTML + **本地预构建** Tailwind CSS(没用 CDN,国内访问稳)
- Vanilla JS + 轻量 i18n 字典(就 240 行)
- Leaflet.js + OSM 暗色瓦片
- GitHub Pages 部署,`git push` 90 秒上线
- 站点 ~50KB,手机端也好用

GitHub: https://github.com/freefoodmap/freefoodmap.github.io
(挂在 freefoodmap 组织下面,不是个人账号,方便协作者加入)

需要你们帮忙的:

1. **如果你在某个城市**,帮我们核对当地的 food bank、食物柜、
   街头发放点,或者直接提 PR 加新点。`data.js` 一行一个。
2. **如果你会西班牙/葡萄牙/法/阿拉伯/印地/斯瓦希里语**,
   `i18n.js` 里 240 个 key 翻一份就好。
3. **如果你做开源 / 做公益 / 做华人学生会**,
   #ambassadors 区块在找你,5 个空位里有你的。

回帖见。

— Andy
```

## 评论区应答

### "已经有很多 food bank 地图了,你这个有什么不同?"

```
确实有 Google Maps / Apple Maps 上的散点。但:

1. 大多数英文,中文用户基本搜不到(比如绿洲盛食社);
2. 没有按"免费/对外/非营销"过滤;
3. 没有"如何自己开始做"的指南;
4. 没有"做这事的人"的连接(本地联络人 + ambassador 列表)。

所以更像是 "一个中文友好的、面向'想加入'而非'想领饼'的人
的目录 + 行动手册"。
```

### "一个人/小团队维护 31 个国家数据靠谱吗?"

```
诚实回答:目前不靠谱。60+ 点我自己整理的,31 个国家里我亲
眼见过 1 个。所以 #ambassadors 区块就是为这个 — 找 31+ 个本地
联络人,每人负责自己的城市。

第 1 版的 Google Form 提交流程我刚加了,但还没接后端(数据先
存 localStorage)。GitHub issue 模板里有一份结构化的提交表。
```

### "小唐的故事真假的?"

```
B 站搜"小唐酱香饼"前 5 个视频都是他本人/相关账号发的,257 万+
播放。他本人 Douyin @xiaotang688,确实有几十万粉。

具体到"13 万保释金"和"2029 竞选"这两个时间点,网上有不同口径,
我标了"改编自小唐视频原话"。站点本身不依赖这些细节 — 数据是
独立的,可以被任何人验证。
```

### "想参与,Java/Python 后端能做啥?"

```
不需要后端。需要的是:

- **前端**:tailwind 组件、leaflet 自定义标记、可访问性
- **数据**:你所在城市的 food bank 整理
- **翻译**:i18n.js 一行一个 key
- **外联**:把你认识的 CSSA / NGO 介绍给我

但如果你有强烈偏好,我也想加个简单后端(可能是 Cloudflare
Workers + KV)做表单提交。先看 30 天内能不能纯 PR 撑住。
```

### "为什么用 GitHub Pages 不用 mcode / Vercel / Cloudflare?"

```
试过几个。GitHub Pages:
- 永久 URL(github.io 不会回收)
- 部署 = git push,90 秒上线
- 挂在 org 下面,不挂我个人
- 免费 SSL
- 跟项目本身的开源精神一致

mcode / Vercel / Cloudflare 也好,但每个 URL 都会带平台尾巴
或换地址。公益项目,稳比快重要。
```
