# 🥯 Free Food Map · 目标联系人追踪表

> **30 个目标联系人** — 按"地区 × 角色"矩阵筛选,每格选 1–2 人
> **追踪工具:** 复制此表到 Notion / Airtable,或就在 GitHub issue 里维护
> **目标:** 30 天内转化 10–15 个,90 天内转化 20+

---

## 使用方法

1. 复制此表到 Notion / Airtable / Google Sheets
2. 每联系一个,改 `状态` 列
3. 每周日 review 一次,决定 follow-up
4. 30 天后统计:已联系 / 已回复 / 已转化 / 拒绝
5. 6 个月后没回的移到 `cold-leads/nurture-2026Q4.md`

---

## 状态机

| 状态 | 含义 | 下一步 |
|---|---|---|
| `🟡 待联系` | 还没发邮件 | 写个性化 cold email |
| `🔵 已发` | 已发首封,等 7 天 | 准备 follow-up |
| `🟣 已 follow-up` | 已发 1–2 次 follow-up,等 14 天 | 准备结案 / 转介 |
| `🟢 已回复` | 收到回信,正在对话 | 转化为 ambassador |
| `✅ 转化` | 已加入 #ambassadors,或提了 PR,或加了数据 | 维护关系 |
| `❌ 拒绝` | 明确说 no | 6 个月后再试 |
| `⚪ 无回复` | 45 天内无回 | 移到 nurture 队列 |

## 联系人查找"工作流"

### 1. 找 NGO 联系人(5 分钟/人)

```
Google: "{{org_name}} partnerships"
→ 官网 footer → "Contact us" / "Press" 页面
→ 找 "Director of Partnerships" / "Communications"
→ LinkedIn: 搜 "{{org_name}}" 看 employees
→ Email pattern: 试 partnerships@, press@, info@, hello@
```

### 2. 找 CSSA 联系人(10 分钟/人)

```
Google: "{{university}} CSSA contact"
→ 官网 → /international/student-organizations
→ WeChat 群(已经有的话)
→ 朋友 intro(成功率最高)
```

### 3. 找 Tech 志愿者(15 分钟/人)

```
HN: 找最近在 static / i18n / Leaflet 帖子里发过评论的人
Dev.to: 搜 "static site" / "i18n" / "github pages" tag 的活跃作者
GitHub: 找同类项目提过 PR 的人
V2EX: 创造 / 程序员 节点回帖中提具体技术的人
```

### 4. 找 Translator(20 分钟/人)

```
HN "Who wants to be hired" 月度贴 → 翻评论
Dev.to → tag: i18n, javascript → 找非英语国家作者
LinkedIn: "i18n" + "translator" + "volunteer" 搜索
Upwork: 评分 5 星 + 母语 + 低时薪(公益项目)
```

## 工具快捷入口

- **追踪表:** 复制到 Notion / Airtable
- **Mail merge:** 用 `mailbrew` / `lemnlist` / 自己写 Python 脚本
- **联系人查找:** `apollo.io` / `rocketreach.co` / `hunter.io`(找邮箱)
- **批量 LinkedIn outreach:** `phantombuster` / `linkedin-sales-navigator`

> **不要用** 自动发邮件工具(spam 感强,会毁掉项目声誉)
> **应该用** 邮件追踪(GMail 配 `mailtrack` 或 `yesware`,只看不发)
