# 🥯 Free Food Map · 推广手册

> 这是一个**操作手册**,不是宣传册。
> 目的是让任何 ambassador 都能用模板执行推广动作,版本可控。

## 📁 文件结构

```
promotion/
├── 00-STRATEGY.md           ← 先读这个(整体节奏 + 三类受众)
├── CONTACTS-CHECKLIST.md    ← 30 个目标联系人追踪表
├── POSTS-LOG.md             ← 每次发布的记录 + 30-day 复盘
└── templates/
    ├── HackerNews.md        ← Show HN 帖文 + 评论区应答
    ├── V2EX.md              ← 创造节点贴 + 中文技术圈应答
    ├── DevTo.md             ← 长文(SEO + 长期沉淀)
    ├── Twitter.md           ← 8 条 thread 模板
    ├── WeChat.md            ← 朋友圈 / 群 / 即刻 / 微博 / 小红书
    ├── Cold-Email-1-CSSA.md ← 校园学生组织(高回复率)
    ├── Cold-Email-2-NGO.md  ← 食物银行 / NGO(低回复率,但高价值)
    ├── Cold-Email-3-Church.md ← 教会 / 社区中心(温暖语气)
    └── Cold-Email-4-Tech.md ← 技术志愿者(i18n / 前端)
```

## 🚀 推荐的 30 天启动顺序

| Day | 动作 | 文件 |
|---|---|---|
| 1 (周三) | HN Show HN | `HackerNews.md` |
| 1 (当晚) | V2EX 创造 | `V2EX.md` |
| 2 | Twitter thread | `Twitter.md` |
| 3 | 准备 5 封 CSSA email | `Cold-Email-1-CSSA.md` |
| 4 | 准备 5 封 NGO email | `Cold-Email-2-NGO.md` |
| 5 | 准备 5 封 Tech email | `Cold-Email-4-Tech.md` |
| 6 | 准备 5 封 Church email | `Cold-Email-3-Church.md` |
| 7 (周日) | WeChat 朋友圈 / 即刻 | `WeChat.md` |
| 8 | 发送前 10 封 email | 全部 4 个 |
| 10 | Dev.to 长文 | `DevTo.md` |
| 14 | Email follow-up 1 | 全部 4 个 |
| 21 | Email follow-up 2 | 全部 4 个 |
| 30 | 30-day 复盘 | `POSTS-LOG.md` |

## 🎯 一句话目标

> 30 天内,把 `#ambassadors` 区块从 **1 founder / 0 volunteers** 扩到 **5–10 个跨时区/跨技能的核心协作者**。
